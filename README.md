**Mission Core — in one paragraph**
Small battery-powered sensors watch for water leaks, doors left open, temperature drift and movement. A small computer on site makes sense of them and forwards readings to an online dashboard. The design principle throughout: a dashboard showing readings is a commodity; a system that tells you when it has stopped being able to see is not.

Three things follow from that:

Silence detection — every device is compared against how often it should report, so a sensor that has stopped is announced rather than leaving a stale reading looking current
Store and forward — readings survive a broadband outage and forward afterwards, so a gap in the history means a device failed, not that the connection dropped
Hardware agnostic — two entirely different sensing technologies integrated into one application, so I can specify what suits a site rather than what I stock
